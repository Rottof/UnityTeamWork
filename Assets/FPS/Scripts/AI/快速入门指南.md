# 怪物波次刷新系统 - 快速入门指南

## 5分钟快速设置

### 步骤1：创建管理器
1. 在场景中创建空对象：右键 -> Create Empty
2. 命名为 `WaveSpawnManager`
3. 添加组件：`WaveSpawnManager`

### 步骤2：自动设置玩家
1. 选中 `WaveSpawnManager` 对象
2. 在Inspector面板中点击 `🎯 自动查找玩家` 按钮

### 步骤3：设置小型怪
1. 将你的小型怪预制体拖到 `Small Enemy Prefab` 字段
   - ⚠️ 预制体必须包含：`EnemyController`, `Health`, `NavMeshAgent`

### 步骤4：设置大型怪（可选）
1. 将大型怪预制体拖到 `Large Enemy Prefab` 字段
2. 点击 `📍 创建大型怪刷新点` 按钮创建刷新点
3. 在Scene视图中移动刷新点到合适位置
4. 重复创建多个刷新点（推荐3-5个）

### 步骤5：选择难度预设
- 点击 `简单难度` - 适合新手测试
- 点击 `普通难度` - 默认平衡难度
- 点击 `困难难度` - 高难度挑战

### 步骤6：运行测试
1. 确保场景已烘焙 NavMesh
2. 点击 Play 运行游戏
3. 等待30秒，观察怪物刷新
4. 使用 `🔄 手动刷新一波` 按钮立即测试

## 常用参数调整

### 改变刷新速度
- `Wave Interval`: 默认30秒，改为20秒会更快

### 改变怪物数量
- `Initial Small Enemy Limit`: 第一波数量（默认5）
- `Limit Increase Per Wave`: 每波增加数量（默认2）

### 改变难度增长
- `Health Increase Per Wave`: 血量增长（0.1 = 每波+10%）
- `Damage Increase Per Wave`: 伤害增长（0.1 = 每波+10%）

### 改变刷新范围
- `Spawn Radius`: 小型怪刷新半径（默认15米）

## 预制体设置检查清单

### 小型怪预制体必须有：
- ✅ `EnemyController` - 怪物控制器
- ✅ `Health` - 血量系统
- ✅ `NavMeshAgent` - 寻路系统
- ✅ `Actor` - 角色标识
- ✅ `Collider` - 碰撞体

### 如果怪物会攻击，还需要：
- ✅ `WeaponController` - 武器控制器
- ✅ `ProjectileStandard` - 投射物（在武器子对象上）

### 大型怪预制体：
- 与小型怪相同的组件要求
- 建议更高的血量和伤害值

## 场景要求

### 必需：
- ✅ 烘焙的 NavMesh（Window -> AI -> Navigation -> Bake）
- ✅ `EnemyManager` 对象（通常已存在）
- ✅ 玩家角色（带 `PlayerCharacterController`）

### 推荐：
- 开阔的战斗区域（方便刷新小型怪）
- 战略位置的大型怪刷新点（如入口、高地等）

## 调试工具

### Inspector面板工具：
- `🎯 自动查找玩家` - 自动设置玩家引用
- `📍 创建大型怪刷新点` - 快速创建刷新点
- `🔍 自动查找所有刷新点` - 收集场景中的刷新点
- `🔄 手动刷新一波` - 立即触发刷新（运行时）
- `🔁 重置波次` - 清空所有怪物（运行时）

### 可视化：
- **黄色圆圈**：小型怪刷新范围
- **绿色球体**：大型怪刷新点（空闲）
- **红色球体**：大型怪刷新点（已占用）
- **蓝色箭头**：大型怪朝向

### 运行时信息：
- 左上角面板显示当前波次信息
- Console输出详细刷新日志

## 测试流程

### 1. 基础测试
```
1. 运行游戏
2. 观察是否在30秒后刷新第一波
3. 检查怪物是否在玩家周围刷新
4. 确认怪物数量是否正确（第一波5只）
```

### 2. 数量测试
```
1. 等待第二波刷新（60秒）
2. 如果场上有剩余怪物，确认新刷新数量 = 上限 - 剩余
3. 检查上限是否正确递增（5 -> 7 -> 9）
```

### 3. 难度测试
```
1. 击杀第一波怪物，记录所需攻击次数
2. 击杀第二波怪物，应该更难击杀
3. 观察怪物攻击伤害是否增加
```

### 4. 大型怪测试
```
1. 观察大型怪是否在刷新点生成
2. 击杀大型怪后，等待下一波
3. 确认该刷新点重新刷新大型怪
```

## 常见问题快速解决

### ❌ 怪物不刷新
1. 检查 Inspector 的 `设置验证` 部分
2. 确认场景有 NavMesh
3. 增大 `Spawn Radius`

### ❌ 怪物刷新在地面下
1. 调整预制体的位置
2. 确保 NavMesh 高度正确

### ❌ 怪物不攻击
1. 检查怪物的 `DetectionModule` 设置
2. 确认 `AttackRange` 和 `DetectionRange`

### ❌ 性能问题
1. 降低 `Initial Small Enemy Limit`
2. 降低 `Limit Increase Per Wave`
3. 增加 `Wave Interval`
