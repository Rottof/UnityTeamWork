# 怪物波次刷新系统 使用说明

## 系统概述

这是一个完整的怪物波次刷新系统，实现了以下功能：
- 每30秒自动刷新一波怪物
- 小型怪在玩家周围随机刷新，数量有上限且递增
- 大型怪在固定点位刷新，有则不刷
- 怪物血量和攻击力随波次递增（每波+10%）

## 组件说明

### 1. WaveSpawnManager（主管理器）

这是核心管理组件，负责控制整个波次系统。

#### 主要参数：

**基础设置**
- `player`: 玩家Transform引用（会自动查找）
- `waveInterval`: 波次刷新间隔，默认30秒

**小型怪设置**
- `smallEnemyPrefab`: 小型怪预制体
- `initialSmallEnemyLimit`: 第一波小型怪数量上限（默认5）
- `limitIncreasePerWave`: 每波增加的数量上限（默认2）
- `spawnRadius`: 小型怪刷新半径（默认15米）
- `navMeshSampleDistance`: NavMesh采样范围（默认5米）

**大型怪设置**
- `largeEnemyPrefab`: 大型怪预制体
- `largeEnemySpawnPoints`: 大型怪刷新点列表

**难度设置**
- `healthIncreasePerWave`: 每波血量增长百分比（默认0.1 = 10%）
- `damageIncreasePerWave`: 每波攻击力增长百分比（默认0.1 = 10%）

#### 调试功能：
- 右键菜单 -> `手动刷新一波`：立即触发一波刷新
- 右键菜单 -> `重置波次`：重置系统并清除所有怪物
- 运行时左上角显示波次信息面板

### 2. LargeEnemySpawnPoint（大型怪刷新点）

用于标记大型怪的固定刷新位置。

#### 参数：
- `isActive`: 是否激活该刷新点
- `showGizmo`: 是否显示范围指示器
- `gizmoRadius`: 刷新点可视化半径

#### 可视化：
- 绿色球体：刷新点空闲，可以刷新
- 红色球体：刷新点已有怪物
- 蓝色箭头：指示怪物朝向

### 3. EnemyWaveData（波次数据）

自动添加到每个刷新的怪物上，记录其波次信息和属性加成。

#### 信息：
- `waveNumber`: 怪物所属波次
- `isLargeEnemy`: 是否为大型怪
- `healthMultiplier`: 血量倍率
- `damageMultiplier`: 伤害倍率

## 使用步骤

### 1. 场景设置

1. **创建管理器对象**
   - 在场景中创建空对象，命名为 `WaveSpawnManager`
   - 添加 `WaveSpawnManager` 组件

2. **设置小型怪**
   - 将小型怪预制体拖入 `Small Enemy Prefab` 字段
   - 确保预制体有以下组件：
     - `EnemyController`
     - `Health`
     - `NavMeshAgent`
     - `WeaponController`（如果有攻击）

3. **设置大型怪刷新点**
   - 在场景中需要刷新大型怪的位置创建空对象
   - 添加 `LargeEnemySpawnPoint` 组件
   - 将这些刷新点添加到 `WaveSpawnManager` 的 `Large Enemy Spawn Points` 列表中

4. **设置大型怪预制体**
   - 将大型怪预制体拖入 `Large Enemy Prefab` 字段
   - 确保预制体有相同的组件（同小型怪）

5. **调整参数**
   - 根据游戏难度调整各项参数
   - 建议从默认值开始测试

### 2. 预制体要求

怪物预制体必须包含以下组件：
- `Health`: 用于血量管理
- `EnemyController`: 怪物控制器
- `NavMeshAgent`: 用于寻路（小型怪必需）
- `WeaponController`: 如果怪物会攻击
- `ProjectileStandard`: 如果使用投射物攻击

### 3. 场景要求

- 场景必须烘焙 NavMesh（小型怪刷新需要）
- 场景中必须有 `EnemyManager` 对象
- 场景中必须有玩家（带 `PlayerCharacterController` 组件）

## 工作原理

### 刷新逻辑

**小型怪刷新：**
1. 每30秒触发一次刷新
2. 计算需要刷新的数量：`上限 - 当前场上数量`
3. 在玩家周围半径范围内随机寻找NavMesh上的有效位置
4. 避免在玩家正前方60度范围内刷新
5. 应用当前波次的属性加成

**大型怪刷新：**
1. 每30秒检查所有刷新点
2. 如果刷新点没有怪物，则刷新一只
3. 如果刷新点已有怪物（或怪物还未死亡），跳过
4. 应用当前波次的属性加成

### 难度递增

- 第1波：血量×1.0，伤害×1.0
- 第2波：血量×1.1，伤害×1.1
- 第3波：血量×1.2，伤害×1.2
- 以此类推，无上限

### 数量递增

- 第1波：上限5只
- 第2波：上限7只
- 第3波：上限9只
- 以此类推，每波+2

## 调试技巧

1. **查看刷新范围**
   - 选中 `WaveSpawnManager` 对象
   - Scene视图会显示黄色圆圈（小型怪范围）和红色球体（大型怪刷新点）

2. **监控波次信息**
   - 运行游戏时，左上角会显示当前波次信息
   - 包括波次数、数量上限、场上怪物数、属性倍率等

3. **手动测试**
   - 右键点击 `WaveSpawnManager` 组件
   - 选择 `手动刷新一波` 立即触发刷新
   - 选择 `重置波次` 清空所有怪物

4. **查看日志**
   - Console 会输出每波刷新的详细信息
   - 包括刷新数量、属性加成等

## 常见问题

### Q: 小型怪不刷新？
A: 检查以下几点：
- 场景是否烘焙了NavMesh
- 玩家周围是否有可用的NavMesh区域
- `spawnRadius` 是否足够大
- 检查Console是否有"无法找到合适的刷新位置"警告

### Q: 大型怪不刷新？
A: 检查以下几点：
- 是否添加了 `LargeEnemySpawnPoint` 对象
- 刷新点是否添加到了列表中
- 刷新点的 `isActive` 是否为true
- 检查刷新点是否已有怪物（红色球体）

### Q: 怪物属性没有增强？
A: 检查以下几点：
- 怪物是否有 `Health` 组件
- 怪物是否有 `WeaponController` 和 `ProjectileStandard` 组件
- 查看Console日志确认属性是否正确应用
- 查看怪物上的 `EnemyWaveData` 组件确认倍率

### Q: 性能问题？
A: 可以调整以下参数：
- 降低 `initialSmallEnemyLimit`（减少初始数量）
- 降低 `limitIncreasePerWave`（减缓数量增长）
- 增加 `waveInterval`（延长刷新间隔）
- 减少大型怪刷新点数量

## 扩展建议

可以根据需要进行以下扩展：

1. **多种怪物类型**
   - 修改 `WaveSpawnManager` 添加怪物类型列表
   - 随机或按波次选择不同类型

2. **特殊波次**
   - 添加Boss波（例如每5波刷新一次Boss）
   - 添加精英怪概率

3. **动态难度**
   - 根据玩家击杀速度调整难度
   - 根据玩家血量调整刷新频率

4. **刷新特效**
   - 在刷新位置添加传送门特效
   - 添加刷新音效

5. **UI提示**
   - 添加波次开始提示
   - 添加怪物剩余数量显示
   - 添加下一波倒计时

## 注意事项

1. 确保场景中只有一个 `WaveSpawnManager`
2. 第一波刷新会在游戏开始30秒后触发（可以在Start中添加立即刷新）
3. 大型怪只有在死亡后才会重新刷新
4. 小型怪数量上限会持续增长，注意性能问题
5. 属性加成是乘法叠加，后期怪物会非常强
